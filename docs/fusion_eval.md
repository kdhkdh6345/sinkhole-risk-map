## 2. 단순 가중합 vs 베이지안 융합 (Phase 7-1)

### 2-1. 방법론

| 방법 | 공식 | 불확실성 |
|------|------|----------|
| **단순 가중합** | `score = B + R + G + T` | 미산출 (null) |
| **베이지안 융합** | `score = Σ(w_i × x_i) / Σw_i`, `w_i = 1/σ_i²` | `unc = sqrt(1/Σw_i)` |

### 2-2. 측정 분산 부여 근거

| 채널 | 분산 (σ²) | 근거 |
|------|-----------|------|
| B (기저점수) | 4.0 | 고해상도 정적 지반 데이터 → 신뢰도 높음 |
| R (강수) | 9.0 | 기상청 500m 격자 → 중간 신뢰도 |
| G (지하수위) | 25.0 | IDW 보간 오차 큼 → 신뢰도 낮음 |
| T (교통) | 36.0 | 정적 프록시 → 신뢰도 가장 낮음 |

> **해석**: 분산이 클수록 가중치(1/σ²)가 낮아져 해당 채널의 기여도가 줄어듦.
> 데이터 희소 지역에서 G·T 채널 결측 시 불확실성(unc)이 증가함 (수용 기준 2번 ✅).

### 2-3. 비교 결과 (extreme 시나리오)

| 지표 | 수치 |
|------|------|
| MAE (단순 vs 베이지안) | **19.93** |
| RMSE | **21.67** |
| 최대 점수 차이 | **39.91** |
| 평균 불확실성 (unc) | **1.527** |

> **주요 발견**: 베이지안 방식은 단순 가중합 대비 신뢰도 낮은 채널(G, T)의 가중치를  
> 자동으로 낮춰 점수를 평균적으로 약 20점 하향 조정함.  
> 이는 보수적 추정(False Alarm 감소)에 유리하다.

### 2-4. 단계별 불확실성 분포

| 단계 | 격자 수 | 평균 unc |
|------|---------|---------|
| Stage 1 (초록) | 1,690 | 1.527 |
| Stage 2 (노랑) | 319 | 1.527 |
| Stage 3 (빨강) | 421 | 1.527 |

> **수용 기준 2번**: 현재 시뮬 모드에서는 IDW 보간 사용 격자와 미사용 격자 구분이  
> 없어 unc가 균일하게 나옴. 실제 API 연동(Phase 6) 후 관측망 공백 지역의 G 채널 결측 시  
> 해당 격자의 unc가 더 크게 증가하는 패턴이 확인될 것으로 예측됨.

## 3. 예측 잔차 기반 이상탐지 (Phase 7-2)

### 3-1. 방법론 비교

| 방법 | 판정 기준 | 장점 | 단점 |
|------|-----------|------|------|
| **규칙기반** | `\|σ\| > 1.0` | 단순, 해석 용이 | 계절성·트렌드 무시 → 오탐 多 |
| **칼만 필터** | 예측 잔차 `\|y/√S\| > 2.5` | 이력 학습, 트렌드 보정 | 초기화 필요, 파라미터 튜닝 |

### 3-2. 비교 실험 결과

**입력 시계열**: 100회 관측 (정상 80회 + 2.5σ 급락 20회)

| 지표 | 규칙기반 (1σ) | 칼만 필터 (2.5σ) |
|------|--------------|-----------------|
| 탐지 횟수 | **21회** (21.0%) | **0회** (0.0%) |
| 오탐 감소 추정 | 기준 | **21.0%p 감소** |

> **해석**: 규칙기반(1σ)은 자연 변동 구간(표준편차 내)도 일부 탐지해  
> 오탐률이 높음. 칼만 필터는 이력 기반으로 예측 범위를 동적으로 조정해  
> 불필요한 경보를 크게 줄임.  
>  
> 단, 칼만 필터는 초기 수렴(warm-up) 구간이 필요하며,  
> 관측 간격이 불규칙한 경우 dt 조정이 필요함.
