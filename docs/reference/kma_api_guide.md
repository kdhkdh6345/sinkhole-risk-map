# 기상청 ASOS 시간별 강수량 조회

## 셋업 (5분)

1. https://apihub.kma.go.kr 회원가입 (메일 인증) — 가입 시 인증키 자동 발급, 마이페이지 > 인증키 현황에서 확인
2. 좌측 메뉴 지상관측 > 종관기상관측(ASOS)에서 **"시간자료"**와 **"시간자료(기간 조회)"** 두 개를 "API 활용신청" (활용 목적 입력하면 즉시 완료 — 별도 승인 대기 없음)
3. `pip install requests pandas`
4. `export KMA_API_KEY="발급받은키"`

## 실행

```bash
# 지점 목록 → asos_stations.csv (위경도, 해발고도 포함)
python kma_asos.py stations

# 수원(119) 최근 30일 시간자료 → CSV
python kma_asos.py fetch --stn 119 --days 30

# 서울(108) 기간 지정
python kma_asos.py fetch --stn 108 --tm1 202607010100 --tm2 202608010000
```

강수량 컬럼: `RN`(해당 시각 시간강수량 mm), `RN_DAY`(당일 누적 mm), `RN_INT`(강수강도 mm/h).
결측(-9, -99 계열)은 빈 값(NaN)으로 변환됨. 원본 응답은 `asos_*_raw.txt`로 백업됨.

## 확인사항 답변

**1. 시간 단위 데이터가 나오는가?** → 나옴. kma_sfctm3(기간 조회)로 1시간 간격 데이터 제공. 분 단위(AWS 매분자료)도 별도 API로 존재하므로 지연반응 분석 정밀도를 더 올리고 싶으면 그쪽도 옵션.

**2. 관측 지점 수와 코드 체계** → ASOS는 전국 약 96개 지점(2020.4 기준). 코드는 2~3자리 국내 지점번호(예: 108 서울, 119 수원, 133 대전, 159 부산). `stations` 명령으로 최신 목록을 API에서 직접 받는 게 정확하고, `asos_stations_static.csv`는 오프라인 참조용. 참고: 촘촘한 공간 해상도가 필요하면 AWS(방재기상관측, 500개+ 지점)가 있지만 ASOS보다 품질관리 수준이 낮음.

**3. 과거 조회 범위** → 1904년 4월~현재 (지점별 상이. 서울 1907년~, 최근 신설 지점은 짧음). 수십 년치 시계열 분석 가능.

**4. 호출 제한** → API허브는 무료이며 고정 숫자 대신 "회원 유형·활용 목적에 따라 차등 적용" 방식. 실무적으로 중요한 제약은 **기간 조회 1회당 최대 31일**. 1년치 = 지점당 12회 호출이라 부담 없음 (스크립트가 자동 분할 + 0.5초 간격 처리). 참고로 공공데이터포털 쪽 동일 데이터는 개발계정 일 10,000건 제한.

## API허브 vs 공공데이터포털

| | API허브 (추천) | 공공데이터포털 |
|---|---|---|
| 승인 | 즉시 (가입만 하면 됨) | 자동승인이지만 절차 김 |
| 형식 | 텍스트(파싱 필요, 스크립트 처리됨) | XML/JSON |
| 기간 조회 | 1회 31일 | 페이징 필요 |

둘 다 월요일에 바로 쓸 수 있을 가능성이 높습니다. "하루 이틀 승인 대기"는 대부분 불필요 — API허브는 가입 즉시 키가 나옵니다.

## 주의사항

- 응답 인코딩은 EUC-KR (스크립트에서 처리됨)
- `RN` 결측(-9.0)과 무강수(0.0)는 다름. `IR` 컬럼이 3이면 무강수 또는 결측
- 컬럼 수가 문서와 다르게 나오면 경고가 뜨고 raw 파일로 대조 가능하게 해둠 — 첫 실행 때 raw 파일 한번 열어서 컬럼 매칭 확인 추천
